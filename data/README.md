# Research Paper - GamiFi ledger data

These files preserve the 6 September 2026 ledger snapshot for independent reproduction.

- [Complete ledger](Research_Paper_GamiFi_Ledger.json): all five sheets, cell values, formula expressions, and stored formula results. Row/column positions are preserved.
- CSV tables: rows beginning at each original table header (row 8), with stored values. A blank cached result is not a verified zero. Formula expressions and the contextual notes above the tables remain in the JSON.
- The transfer table has 262 rows; the vesting table has 7,495 funded schedules.

The values have not been recalculated against a live node for this edition. Keep chain, token, block height, decimals and exact-amount text when reproducing them. Do not add successive transfer legs as independent money raised or lost. Wallet activity does not establish a named person's custody or beneficial ownership. Consult the later reports for corrections to historical interpretations.
