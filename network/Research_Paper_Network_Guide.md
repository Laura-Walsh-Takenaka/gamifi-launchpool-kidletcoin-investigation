# Research Paper — Public Crypto Network

An interactive index of historical public crypto research concerning Laura Walsh / Takenaka's documented professional roles and the associated projects, companies and token movements. Source observations run principally through 7 September 2026; this edition was prepared on 20 September 2026. It does not claim a fresh registry or blockchain check.

Download `Research_Paper_Public_Crypto_Network.html` and open it in a browser with JavaScript enabled. The viewer contains its own records and needs no installation or network connection for those records. Public source links need internet access. GitHub's file view shows the HTML source rather than running the viewer.

Use **Read first** for correction precedence, **Records** for sources, datasets and the exact ledger, **Needs** for unresolved questions, and the search box to find names, wallets and findings. Graph links describe documented or reported relationships; they do not establish wrongdoing or personal control of a wallet.
